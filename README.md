# Riga Transit — Telegram Mini App

Мобильная карта общественного транспорта Риги: официальные остановки, поиск, расписание, избранное, геолокация и сообщения пассажиров.

## Функции

- Карта официальных остановок Rīgas satiksme и поиск по названию/номеру маршрута.
- Кластеризация маркеров, GPS и ближайшие остановки.
- Карточка остановки с маршрутами и плановыми отправлениями по направлениям.
- Избранные остановки, история просмотров и нижняя навигация.
- Локальный профиль, отображаемое имя, Telegram Mini App display name/photo, настройки отображения карты.
- Сообщения пассажиров с локальным хранением и двухчасовым сроком действия.

## Расписание и источник данных

Rīgas satiksme публикует статический GTFS на Latvijas Atvērto datu portāls под лицензией CC0 1.0. В расписании отображаются плановые отправления, рассчитанные по GTFS calendar/calendar_dates и stop_times. Это не live arrival prediction: фактические задержки и GPS транспорта не показываются.

Импортёр автоматически обнаруживает новый месячный ZIP через CKAN API. Для ускорения мобильной загрузки времена по остановкам сохраняются в 32 ленивых JSON-шарда; клиент загружает только шард выбранной остановки. Старые монолитные stop_times.json и trips.json не публикуются в frontend assets.

Обновление запускается ежемесячно и вручную через GitHub Actions → Sync official Rīgas satiksme GTFS → Run workflow. Push изменений импортёра также запускает синхронизацию.

## Хранение и ограничения

- Избранное, история, имя профиля и сообщения пассажиров сохраняются в localStorage конкретного браузера.
- Данные Telegram Mini App из initDataUnsafe используются только для отображения имени и фотографии; серверная проверка подписи, полноценная учётная запись и межустройственная синхронизация пока не реализованы.
- Сообщения сообщества пока не синхронизируются между пользователями.
- Планировщик маршрутов и пересадки не входят в текущий интерфейс.
