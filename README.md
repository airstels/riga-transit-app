# Riga Transit — Telegram Mini App

Красивая карта остановок Риги + возможность добавлять информацию о проверках, заполненности и т.д.

## Что умеет

- Тёмная красивая карта Риги
- Остановки (сейчас основные + популярные)
- Нажатие на остановку → карточка
- Добавление сообщений: «Проверка», «Забит», «Опаздывает» и др.
- Работает внутри Telegram как Mini App

---

## Пошаговая инструкция (для человека, который не программист)

### Шаг 1. Создай Telegram-бота

1. Открой Telegram
2. Найди бота **@BotFather**
3. Напиши ему `/newbot`
4. Придумай имя (например: `Riga Transit Map`)
5. Придумай username (должен заканчиваться на `bot`, например: `riga_transit_map_bot`)
6. BotFather даст тебе **токен** (длинная строка типа `7123456789:AAH...`).  
   **Сохрани его!** Он понадобится позже.

### Шаг 2. Настрой Mini App у бота

1. В @BotFather напиши `/mybots`
2. Выбери своего бота
3. Нажми **Bot Settings** → **Menu Button**
4. Нажми **Configure menu button**
5. Вставь ссылку, которую получишь после деплоя (см. шаг 4)
6. Напиши название кнопки, например: `Открыть карту`

### Шаг 3. Задеплой приложение на Vercel (бесплатно)

1. Зайди на сайт [https://vercel.com](https://vercel.com) и зарегистрируйся через GitHub
2. New Project → Import репозиторий `airstels/riga-transit-app`
3. Deploy
